# Hibernate con Spring Boot - Clase 1

Este proyecto es una introducción al uso de **Hibernate** dentro de un proyecto **Spring Boot**. Forma parte del curso dictado en EducaciónIT.

## 🧠 Contenidos

- Creación de un proyecto Spring Boot
- Uso de Hibernate como proveedor JPA
- Configuración de conexión a base de datos MySQL
- Uso del EntityManager
- Mapeo de entidad `Empresa`
- Persistencia de datos usando un servicio
